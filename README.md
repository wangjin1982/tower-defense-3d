# 🛡️ 星际防线 3D（塔防）

科幻风格 3D 塔防游戏，纯前端实现（Three.js r160 本地 vendored，无任何外部依赖）。
**无尽模式**：第 20 波全体总攻后怪潮无限增强，直到核心失守为止。

## 运行

```bash
cd tower-defense-3d
npm start          # 等价于 python3 -m http.server 8124
```

浏览器打开 http://localhost:8124

> 必须通过 HTTP 访问（ES Module 不支持 file:// 直开）。

## 玩法

- 敌人从**红色传送门**出发，沿发光路线冲向**绿色核心**；漏一个扣核心耐久（❤️），归零失败。
- 点击底部建造栏（或按 `1-4`）选塔，再点击空地建造；点击已建炮塔可**升级（最高 3 级）**或**出售（返还 70%）**。

**攻城兽**：每逢偶数波出现（数量逐波递增、封顶 4），走得慢但血厚甲高，专拆防御塔——

## 难度

| 难度 | 敌人生命 | 速度 | 护甲 | 初始金币 | 核心耐久 | 变化 |
|------|---------|------|------|---------|---------|------|
| 🟢 普通 | ×1.08 | ×0.73 | 60% | 220 | 20 | 标准节奏，BOSS 每 7 波 |
| 🔴 困难 | ×1.44 | ×0.98 | 80% | 200 | 15 | 疾行者第 2 波就出现；第 8 波起刷精英怪 |
| 💀 地狱 | ×1.8 | ×1.22 | 100% | 180 | 10 | 第 1 波就有疾行者、第 3 波重装甲；BOSS 每 5 波一波；第 4 波起精英横行（22% 概率）；波次奖励打折 |

怪物三维属性（生命/速度/护甲）按 **地狱:困难:普通 = 5:4:3** 等比缩放，地狱为基准。

**护甲**：每次受击减免固定伤害（至少受 1 点）。地狱满档护甲：🟢步兵 4 · 🟡疾行者 3 · 🩷重装甲 8 · 🟣BOSS 12（困难 80% · 普通 60%）。护甲克高频低伤（地狱机枪 9 伤只剩 5），高单发的狙击/火箭几乎不受影响——难度越高越考验塔的搭配。披甲敌人外观呈暗色金属质感。

**阶段强化**：**每隔 3 关**（第 3、6、9、12、15、18 波）敌人强化等级 +1，每级叠加：生命 ×1.10、速度 ×1.045、护甲 +0.5。**第 15 波起全属性额外 ×1.5（狂暴）**；**第 20 波全体总攻**——所有种类敌人（含超级怪兽+全部载具）同时出动。升级波开始时会有 🧬 强化预警。

精英怪：2.2 倍血、2.5 倍赏金、体型更大带旋转金环，漏过多扣 1 点核心耐久。
**💀 地狱专属**：精英被击杀时会在原地沿路径分裂成两只加速疾行者（60% 血量、半价赏金），注意补防。

## 操作

| 按键 | 功能 |
|------|------|
| 左键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 1-4 | 选择炮塔 |
| 空格 | 开始下一波 |
| Esc | 取消建造/取消选中 |
| U | 升级选中的炮塔 |
| P / M | 暂停 / 静音 |

> 调试：控制台暴露了 `__td`（游戏实例），可用于测试，例如 `__td.startNextWave()`。

## 结构

```
index.html        页面骨架
style.css         UI 主题
vendor/three.module.js   Three.js r160（本地）
js/
  config.js       数值配置（塔/敌人/波次）
  map.js          格子地图、路径、场景搭建
  enemies.js      敌人移动/血条/死亡动画
  towers.js       炮塔模型/瞄准/开火/升级
  projectiles.js  子弹与火箭（追踪 + 溅射）
  effects.js      粒子/爆炸/扩散环
  audio.js        WebAudio 程序化音效
  input.js        轨道相机 + 格子拾取
  ui.js           DOM 界面层
  game.js         波次/经济/主逻辑
  main.js         渲染器与主循环
```
